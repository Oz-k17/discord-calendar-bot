# NAS に置いて、何人かで使う

ViViD Edit は全部ブラウザの中で動くので、サーバは「ファイルを配るだけ」で足ります。
NAS に nginx を 1 つ立てて、**アプリと共有素材を同じ口から配る**のがここでの構成です。

これで得られるもの:

- 配布が URL 1 つになる（各自インストール不要、iPad でも PC でも同じ）
- 更新が NAS のファイル差し替えだけで済む（全員に配り直さなくていい）
- 素材をコピーせずに参照できる（各自のブラウザの保存枠を食わない）
- プロジェクトをファイル 1 個で渡せる（相手の環境でも同じ素材が開く）
- 外に出ない（インターネットに繋がっていなくても動く）

## なぜ「同じ口」なのか

ブラウザは、ページの出どころと違うホスト・違うポートへの読み込みを既定で止めます（CORS）。
アプリを `:8080`、素材を WebDAV の `:5005` に分けると、素材が読めません。
1 つの nginx から `/` と `/media/` として出せば、同じオリジンになるのでこの問題が起きません。

UGREEN NAS の WebDAV（既定 5005 / 5006）を使わないのはこのためです。

## 置くもの

```
NAS のどこか/vivid-edit/
├── app/              ← このリポジトリの docs/ の中身をそのままコピー
│   ├── index.html
│   ├── assets/
│   └── lab/
├── nginx.conf        ← deploy/nas/nginx.conf
└── docker-compose.yml ← deploy/nas/docker-compose.yml
```

共有素材は別のフォルダで構いません（むしろ別の方がよい）。例:

```
/volume1/video/shared/
├── 2026-09-案件A/
│   ├── cut01.mp4
│   └── bgm.wav
└── ロゴ.png
```

## 手順（UGREEN NAS / UGOS Pro）

1. **ファイルを置く**
   共有フォルダに `vivid-edit/app/` を作り、このリポジトリの `docs/` の中身をコピーします。
   `nginx.conf` と `docker-compose.yml` はその 1 つ上に置きます。

2. **compose の 2 行を書き換える**
   `docker-compose.yml` の `volumes` の、左側のパスを実際の場所に合わせます。

   ```yaml
   - /volume1/docker/vivid-edit/app:/srv/app:ro   # ← アプリを置いた場所
   - /volume1/video/shared:/srv/media:ro          # ← 共有したい素材フォルダ
   ```

   素材側の `:ro`（読み取り専用）は外さないでください。編集アプリから素材を消せる必要はありません。

3. **Docker で立ち上げる**
   UGOS Pro の `Docker` → `プロジェクト` → `作成` を開き、`docker-compose.yml` の中身を貼って作成します。
   コマンドラインは要りません。

4. **開く**
   `http://<NAS の IP>:8080/` を全員に配ります。

5. **素材を入れる**
   編集画面の素材パネル → **「共有」** を押すと、`/media/` の中身が一覧されます。
   選んで追加すると、**コピーせずに参照**として入ります。

## 更新のしかた

`app/` の中身を、新しい `docs/` の中身で差し替えるだけです。コンテナはそのままで構いません。
`index.html` にはキャッシュを持たせていないので、各自が再読み込みすれば新しい版になります。

## プロジェクトの受け渡し

`設定` → `プロジェクトの受け渡し` から、編集内容をファイル 1 個（`.vivid.json`）で書き出せます。
受け取った人は同じ画面の「プロジェクトを開く」で開けます。

素材は**在り処だけ**が入っているので、相手にも同じ共有フォルダが見えている必要があります。
取り込み（ファイル選択で入れた）素材はその端末の中にしか無いため運べません。
書き出すときに、運べない素材があればその名前を知らせます。

## 知っておくこと

- **同時編集はできません。** プロジェクトと設定は各自のブラウザの中にあります。共有されるのは素材だけです。
- **LAN 内の誰でも開けます。** 絞るなら nginx 側で Basic 認証をかけるか、NAS のファイアウォールで。
- **外からは繋がりません。** 社外から使うなら VPN を挟んでください。
- **iPad の Safari は、長く使わないサイトのデータを消すことがあります。** 大事な編集途中のものは、こまめに書き出しておいてください。

## 素材の一覧が出ないとき

アプリは 3 通りの方法で一覧を読みます。上から順に試し、最初に読めたものを使います。

1. nginx の `autoindex_format json`（この構成はこれ）
2. ふつうの HTML のフォルダ一覧（`autoindex on` だけの場合）
3. フォルダに置いた `media.json`

Web サーバに一覧を出させられない場合は、素材フォルダに `media.json` を置いてください。

```json
["cut01.mp4", "cut02.mp4", "bgm.wav", "素材置き場/"]
```

末尾が `/` のものはフォルダとして扱われます。
